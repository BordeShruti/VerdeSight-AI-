## 🌱 VerdeSight AI :- ESG Intelligence

A full-stack ESG (Environmental, Social, and Governance) web application designed to provide an interactive, modern, and user-friendly platform for ESG information, analysis, insights, and decision support. The ESG website is designed as a decision-support platform for organizations, ESG analysts, investors, managers, and researchers to understand ESG performance, identify risks, and make more informed sustainability-related decisions.

## 🚀 What is VerdeSight AI?

Turn fragmented ESG data into explainable insights, risk alerts, recommendations, and sustainability decisions.

## 🚀 Run Locally

Clone the repository
```text
git clone <YOUR-GITHUB-REPOSITORY-URL>
```
Navigate to the project
```
cd VerdeSight-AI
```

Install dependencies
```
pnpm install
```
Navigate to the client application
```
cd apps/client
```
Start the development server
```
pnpm dev
```
🌐 Access the Application

Open your browser and visit:

http://localhost:3100/0
